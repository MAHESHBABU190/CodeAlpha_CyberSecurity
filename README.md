## Task 2: Basic Network Sniffer A Python script using scapy that captures live network packets and prints the source IP, destination IP, and protocol (TCP/UDP) for each one. File: sniffer.py How to run: 1. Install scapy: pip install scapy 2. Install Npcap (npcap.com) for packet capture on Windows 3. Run as Administrator: python sniffer.py What I learned: Running this showed how much background traffic happens even during normal browsing, and the difference between TCP and UDP packets.
